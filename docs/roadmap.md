# Roadmap

A sequence of work, not a calendar. No dates are given because none have been fixed, and nothing here is a commitment to deliver by a particular time.

## Done

- Public website at kaloop.fun with a live readout of block height, gas price, value locked and nearby trading pairs.
- Contract slot, social links and records section driven by a single register, inert until each fact is announced.
- Brand kit processed into site assets, with a sampled and verified palette.
- Automated checks covering layout at five screen widths, tap target size, reduced motion, loading states, failure states and copy originality.

## Next

1. **Announce the contract.** Publish the token contract address, add it to the register, and let the pinned contract bar become a copy control.
2. **Open the code.** Announce the public repository and link it from the site header.
3. **Open the conversation.** Announce the official X account and link it from the site header.
4. **Publish the parameters.** Fill in every row of the [tokenomics](tokenomics.md) table.
5. **Show the Kaloop market line.** As soon as the contract has a trading pair, the market panel shows its price, change and liquidity next to the nearby pairs.

## Then

6. **Launch flow, first version.** Create a token from a form, review every term, sign from a wallet.
7. **Optional funding path.** A reviewed route that begins on RH Chain, with every amount and fee displayed before approval.
8. **Token pages.** One public page per launched token with its terms, holders and market data.
9. **Wallet management.** Manage a launched token from the wallet that created it.

## Later and undecided

- Governance and how it would be introduced.
- Additional networks.
- Anything that needs an audit before it ships, which will be scheduled once scope is known.

## How this file changes

When an item is finished it moves to **Done** with a short description of what shipped. Items are not removed silently; if one is dropped, the reason is written next to it.
